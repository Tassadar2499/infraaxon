# InfraAxon

Infrastructure-aware agents for evidence-based diagnostics.

InfraAxon is a self-hosted infrastructure diagnostics platform. Register existing components through the Vue console, attach dedicated agents, and investigate incidents using live evidence. The ASP.NET Core shop under `examples/shop` is an independent demonstration, not the platform's domain model.

## Status

Proof of concept under active development. Python/FastAPI platform, Vue/TypeScript console, dedicated agents, LiteLLM and Ollama. See `docs/architecture.md` for the architecture and `docs/operations.md` for startup instructions and limitations.
